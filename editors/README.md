# Editor integrations moved

The VS Code and Zed clients are now maintained in [Foundry](https://github.com/foundry-rs/foundry/pull/16730).

From a Solidity project, install Foundry and run [`forge lsp`](https://github.com/foundry-rs/foundry/pull/16730)
to use the bundled editor integration. The Solar language server remains in
this repository and is consumed by Foundry.
